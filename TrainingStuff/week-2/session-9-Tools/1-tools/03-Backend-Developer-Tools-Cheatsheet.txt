Introduction to Maven:
-------------------
Maven is a build + dependency manager that makes Java projects predictable, portable, and professional.

Why maven?
----------
Automatic dependency management
	Maven downloads required libraries and their dependencies automatically—no manual JAR copying.

Standard project structure
	Enforces a common folder layout so any developer or tool can understand the project instantly.

One-command build
	A single command can compile, test, and package the application consistently.

Eliminates version conflicts
	Maven manages library versions centrally, reducing “works on my machine” issues.

Clean source control
	Only configuration files are committed; binaries are fetched when needed.

Consistent builds everywhere
	Same build output on developer machines, servers, and CI pipelines.

Easy IDE and CI/CD integration
	Works seamlessly with IDEs and build servers without extra setup.

Scales from small to large projects
	Suitable for simple student projects and complex enterprise systems alike.

Introduction to Log4j2

Logging – Basics
-------------------
Logging is mandatory for debugging and production support.

System.out.println() is bad practice:
	Hard to remove later
	Pollutes production logs
	No control (enable/disable, level, destination)
	Logging can be turned ON/OFF and redirected to files, DB, email, etc.

What is Log4j?
--------------
A logging/tracing framework mainly for production environments.

Captures:
	Info, warnings, errors, fatal issues
	Class name, method, line number, date/time
	Logs can go to:
	Console (temporary)
	File (.log)
	Database, Email, Network, etc.
	Logging Frameworks

Common options:
	Log4j
	Logback
	Commons Logging
	java.util.logging

Best Practice Use SLF4J (Simple Logging Facade for Java)
--------------------------------------------------------
Your Code → SLF4J → Log4j / Logback / JUL


Why?
	Decouples code from logging implementation
	Swap logging frameworks without changing code

Unit 5 Assertions
---------------------
1. Assert API
	JUnit 5 provides the Assertions class:

import static org.junit.jupiter.api.Assertions.*;

Assertion methods are used to compare the expected result with the actual result.
----------------------------------------
Expected Value
      ↓
   Assertion
      ↑
Actual Result

Match    → TEST PASS
Mismatch → TEST FAIL


2. assertEquals()
-------------------------
Compares the data/value of two objects.

assertEquals(expected, actual);

Example:
assertEquals(10000, account.getBalance());
assertEquals("John", account.getName());


3. assertNotNull() / assertNull()
----------------------------------
assertNotNull()

Checks that an object is not null.
assertNotNull(account);
assertNull()

Checks that an object is null.
assertNull(account);

4. assertDoesNotThrow()
-------------------------
Checks that a method call does not throw an exception.
assertDoesNotThrow(
    () -> service.getAccountById(1L)
);

If an exception is thrown → TEST FAIL

5. assertSame()
--------------------
Checks whether two references point to the same object.

assertSame(account1, account2);
assertEquals() vs assertSame()
assertEquals()
     ↓
Compares object data/value

assertSame()
     ↓
Compares object references
     ↓
Do both references point to the SAME object?


6. fail()
------------
Manually fails a test.
fail("Test failed");

Useful when a condition should never be reached or when manually controlling test failure.


7. assertArrayEquals()
-----------------------
Compares the contents of two arrays.

assertArrayEquals(expected, actual);

With a failure message:

assertArrayEquals(
    expected,
    actual,
    "Data may not be same in two arrays!"
);


8. assertTrue() / assertFalse()
------------------------------
Used to test a boolean condition.

assertTrue()

Expected condition is true.

assertTrue(account.getBalance() > 0);
assertFalse()

Expected condition is false.

assertFalse(account.getBalance() < 0);


9. assertAll()
------------------
Groups multiple assertions and executes all of them.

assertAll(
    () -> assertEquals(1L, account.getId()),
    () -> assertEquals("John", account.getName()),
    () -> assertEquals(10000, account.getBalance())
);

Useful when you want to check multiple properties of the same object.

public interface BookDao {

public class BookDaoImpl implements BookDao {
	@Override
	public List<String> getBooks() {
		return Arrays.asList("java","rich dad poor dad","java adv");
	}
}


public interface BookService {
	public List<String> getBooks(String subject);
}



public class BookServiceImpl implements BookService {
	private BookDao bookDao;

	public void setBookDao(BookDao bookDao) {
		this.bookDao = bookDao;
	}

	@Override
	public List<String> getBooks(String subject) {
		return bookDao.getBooks().stream().filter(title -> title.contains(subject)).collect(Collectors.toList());
	}

}

Partial Mocking: @Spy
--------------------
  When we want an object in the test class to mock some method(s),
 but also call some actual method(s), then we need partial mocking. 
  This is achieved via @Spy

	Unlike using @Mock, with @Spy, a real object is created, 
	but the methods of that object can be mocked or can be actually called—whatever we need.


Example:
--------
@Repository
public class BookDaoImpl implements BookDao {

public class ListTest {

	@Test
	public void letsMockListSize() {
		List list = mock(List.class);
		Mockito.when(list.size()).thenReturn(10);
		assertEquals(10, list.size());
	}

	@Test
	public void letsMockListSizeWithMultipleReturnValues() {
		List list = mock(List.class);
		Mockito.when(list.size()).thenReturn(10).thenReturn(20);
		assertEquals(10, list.size()); // First Call
		assertEquals(20, list.size()); // Second Call
	}

	@Test
	public void letsMockListGet() {
		List<String> list = mock(List.class);
		Mockito.when(list.get(0)).thenReturn("javatraining");
		assertEquals("javatraining", list.get(0));
		assertNull(list.get(1));
	}

	@Test
	public void letsMockListGetWithAny() {
		List<String> list = mock(List.class);
		Mockito.when(list.get(Mockito.anyInt())).thenReturn("javatraining");
		// If you are using argument matchers, all arguments
		// have to be provided by matchers.
		assertEquals("javatraining", list.get(0));
		assertEquals("javatraining", list.get(1));
	}

}

testing service layer:

package com.bankapp.service;

import com.bankapp.dto.Account;
import com.bankapp.repo.AccountRepo;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.InjectMocks;
import org.mockito.InOrder;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;
import java.util.List;
import static org.junit.jupiter.api.Assertions.*;
import static org.mockito.Mockito.*;

@ExtendWith(MockitoExtension.class)
class AccountServiceImplTest {
    @Mock AccountRepo accountRepo;
    @InjectMocks AccountServiceImpl service;

    @Test
    void depositsMoneyAndPersistsUpdatedAccount() {
        Account account = new Account(1, "raj", 2_000);
        when(accountRepo.getAccountById(1)).thenReturn(account);
        service.deposit(1, 500);
        assertEquals(2_500, account.getBalance());
        verify(accountRepo).updateAccount(account);
    }

    @Test
    void rejectsZeroOrNegativeDepositBeforeRepositoryAccess() {
        assertThrows(IllegalArgumentException.class, () -> service.deposit(1, 0));
        assertThrows(IllegalArgumentException.class, () -> service.deposit(1, -10));
        verifyNoInteractions(accountRepo);
    }

    @Test
    void rejectsNaNDeposit() {
        assertThrows(IllegalArgumentException.class, () -> service.deposit(1, Double.NaN));
        verifyNoInteractions(accountRepo);
    }

    @Test
    void rejectsDepositWhenAccountDoesNotExist() {
        when(accountRepo.getAccountById(404)).thenReturn(null);
        assertThrows(IllegalArgumentException.class, () -> service.deposit(404, 100));
        verify(accountRepo, never()).updateAccount(any());
    }

    @Test
    void withdrawsMoneyWhenBalanceIsSufficient() {
        Account account = new Account(1, "raj", 2_000);
        when(accountRepo.getAccountById(1)).thenReturn(account);
        service.withdraw(1, 500);
        assertEquals(1_500, account.getBalance());
        verify(accountRepo).updateAccount(account);
    }

    @Test
    void rejectsWithdrawalWhenBalanceIsInsufficient() {
        Account account = new Account(1, "raj", 200);
        when(accountRepo.getAccountById(1)).thenReturn(account);
        assertThrows(IllegalStateException.class, () -> service.withdraw(1, 500));
        assertEquals(200, account.getBalance());
        verify(accountRepo, never()).updateAccount(any());
    }

    @Test
    void rejectsWithdrawalOfNegativeAmount() {
        assertThrows(IllegalArgumentException.class, () -> service.withdraw(1, -1));
        verifyNoInteractions(accountRepo);
    }

    @Test
    void transfersMoneyAndUpdatesBothAccounts() {
        Account from = new Account(1, "raj", 2_000);
        Account to = new Account(2, "ekta", 1_000);
        when(accountRepo.getAccountById(1)).thenReturn(from);
        when(accountRepo.getAccountById(2)).thenReturn(to);

        service.transfer(1, 2, 500);

        assertEquals(1_500, from.getBalance());
        assertEquals(1_500, to.getBalance());
        InOrder order = inOrder(accountRepo);
        order.verify(accountRepo).getAccountById(1);
        order.verify(accountRepo).getAccountById(2);
        order.verify(accountRepo).updateAccount(from);
        order.verify(accountRepo).updateAccount(to);
    }

    @Test
    void rejectsTransferToSameAccount() {
        assertThrows(IllegalArgumentException.class, () -> service.transfer(1, 1, 100));
        verifyNoInteractions(accountRepo);
    }

    @Test
    void rejectsTransferWhenSourceHasInsufficientBalance() {
        Account from = new Account(1, "raj", 100);
        Account to = new Account(2, "ekta", 500);
        when(accountRepo.getAccountById(1)).thenReturn(from);
        when(accountRepo.getAccountById(2)).thenReturn(to);

        assertThrows(IllegalStateException.class, () -> service.transfer(1, 2, 200));
        assertEquals(100, from.getBalance());
        assertEquals(500, to.getBalance());
        verify(accountRepo, never()).updateAccount(any());
    }

    @Test
    void rejectsTransferWhenDestinationDoesNotExistWithoutChangingSource() {
        Account from = new Account(1, "raj", 2_000);
        when(accountRepo.getAccountById(1)).thenReturn(from);
        when(accountRepo.getAccountById(2)).thenReturn(null);

        assertThrows(IllegalArgumentException.class, () -> service.transfer(1, 2, 500));
        assertEquals(2_000, from.getBalance());
        verify(accountRepo, never()).updateAccount(any());
    }

    @Test
    void returnsAccountById() {
        Account account = new Account(1, "raj", 2_000);
        when(accountRepo.getAccountById(1)).thenReturn(account);
        assertSame(account, service.getAccountById(1));
        verify(accountRepo).getAccountById(1);
    }

    @Test
    void throwsWhenRequestedAccountDoesNotExist() {
        when(accountRepo.getAccountById(999)).thenReturn(null);
        assertThrows(IllegalArgumentException.class, () -> service.getAccountById(999));
    }

    @Test
    void returnsAllAccounts() {
        List<Account> expected = List.of(new Account(1, "raj", 2_000));
        when(accountRepo.getAllAccounts()).thenReturn(expected);
        assertEquals(expected, service.getAllAccounts());
        verify(accountRepo).getAllAccounts();
    }
}

/** Integration of real service + real in-memory repository; no Mockito and no Spring. */
class AccountServiceIntegrationTest {
    private AccountService service;

    @BeforeEach
    void setUp() {
        service = new AccountServiceImpl(new AccountRepoMapImpl());
    }

    @Test
    void depositIsPersistedInRepository() {
        service.deposit(1, 500);
        assertEquals(2_500, service.getAccountById(1).getBalance());
    }

    @Test
    void withdrawIsPersistedInRepository() {
        service.withdraw(2, 700);
        assertEquals(1_300, service.getAccountById(2).getBalance());
    }

    @Test
    void transferUpdatesBothAccounts() {
        service.transfer(1, 2, 600);
        assertEquals(1_400, service.getAccountById(1).getBalance());
        assertEquals(2_600, service.getAccountById(2).getBalance());
    }

    @Test
    void transferPreservesTotalMoney() {
        double before = service.getAllAccounts().stream().mapToDouble(Account::getBalance).sum();
        service.transfer(1, 2, 350);
        double after = service.getAllAccounts().stream().mapToDouble(Account::getBalance).sum();
        assertEquals(before, after, 0.0001);
    }

    @Test
    void completeBankingWorkflowProducesExpectedBalances() {
        service.deposit(1, 1_000);   // Raj: 3,000
        service.withdraw(2, 500);    // Ekta: 1,500
        service.transfer(1, 2, 1_000); // Raj: 2,000; Ekta: 2,500

        assertAll(
            () -> assertEquals(2_000, service.getAccountById(1).getBalance()),
            () -> assertEquals(2_500, service.getAccountById(2).getBalance())
        );
    }

    @Test
    void insufficientWithdrawalDoesNotChangeBalance() {
        assertThrows(IllegalStateException.class, () -> service.withdraw(1, 9_000));
        assertEquals(2_000, service.getAccountById(1).getBalance());
    }

    @Test
    void invalidAccountIsReported() {
        assertThrows(IllegalArgumentException.class, () -> service.deposit(999, 100));
    }

    @Test
    void invalidAmountIsRejected() {
        assertThrows(IllegalArgumentException.class, () -> service.deposit(1, -100));
    }
}
